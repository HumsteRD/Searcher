Family: “Segoe UI Variable Display”, fallback “Segoe UI”. Console only: “Cascadia Mono”, fallback “Consolas”. Caps are typed as caps in the source string — QSS has no text-transform. Tracking is set in code with QFont::setLetterSpacing.
SPACING, RADII, BORDERS, SIZES
Spacing scale4 · 8 · 12 · 16 · 20 · 24 · 28 · 32 · 36 — every padding, margin and gap. Centering offsets are derived, not tokens.
Radii2 nav indicator · 4 progress, log level badge · 6 pills, compact buttons · 8 buttons, inputs, window · 12 cards, tables, toggle track · 16 hero, process card, modal · 20 hero icon tile. Never on a table cell.
Border width1px solid, always. Focus recolours the existing 1px border, so nothing shifts by a pixel.
FrameSidebar 216 (was 232 — the tables need the 16px back), title strip 56, page padding 24 / 28 / 28.

Table densityHeader 40, row 40 (cap 44), cell padding 0 16, 14px text on a 20px line → 10px of air above and below.
Stretch to 1920Sidebar fixed. Cards and tables take the extra width; Name / Source / Original location absorb it, other columns keep their px. Tables take the extra height; Home and Settings park it in a bottom spacer.
